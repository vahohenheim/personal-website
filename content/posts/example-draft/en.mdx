This is an example draft. It shows what a post looks like and only appears in development
and on preview deployments: as long as `draft: true` is set in `lib/constants/posts.ts`, it has no page, no link and no
feed entry on the live site.

## A heading

A post starts straight with a paragraph: the title of the page comes from the registry.
Headings start at `##`.

- a bulleted list;
- a [link](https://www.valentinbourreau.com/en/);
- some **important** text.

### A subheading

1. a numbered list;
2. then the rest.

> A sentence worth remembering goes in a pull quote.

## Code

```ts
const answer = 42;
```
